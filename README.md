# 📊 Sales Dashboard using Power BI

## 📌 Overview
This project presents an interactive **Sales Dashboard** built using Microsoft Power BI as part of the *Power BI for Beginners: Interactive Dashboard Fundamentals* certification on Coursera. It provides insights into sales performance, profit trends, and regional analysis.

---

## 🎯 Objective
To analyze sales data and build a dynamic dashboard that helps stakeholders monitor performance, identify trends, and make data-driven decisions.

---

## 🛠️ Tools & Technologies
- Microsoft Power BI  
- Power Query (Data Cleaning & Transformation)  
- DAX (Basic Calculations)  
- Excel / CSV Dataset  

---

## 📂 Features
- Cleaned and transformed raw sales data using Power Query  
- Created data model with relationships (Sales, Product, Region, Date)  
- Designed interactive visuals (Bar charts, Line charts, KPI cards)  
- Implemented slicers for filtering by Region, Category, and Date  
- Built a user-friendly and responsive dashboard layout  

---

## 📊 Key Metrics
- Total Sales  
- Total Profit  
- Sales by Region  
- Sales by Category  
- Monthly Sales Trend  

---

## 📈 Key Insights
- Identified top-performing regions contributing to maximum sales  
- Observed monthly trends and seasonal variations in revenue  
- Compared category-wise performance to highlight best-selling products
